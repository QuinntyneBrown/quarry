Support

What is supported, in writing.

These are not aspirations. They are the values in support-matrix.json, and the build checks them.

The runtime, engine, and deprecation commitments
Commitment Value
Angular >=21.0.0 <22.0.0
Node >=22.0.0 <23.0.0
Browsers Chromium, Firefox, and WebKit — the current release and the two before it
Deprecation Announced two minor releases before removal
Bundle 400 KiB gzip ceiling; the theme stylesheet has its own 30 KiB ceiling
Peer dependency @angular/cdk, on a version your application chooses

Alongside the components, the package publishes 55 directives, typed interfaces for every input and output, and a small testing harness — 491 public exports in total, each one recorded in the generated API surface document so a diff has to be reviewed before it can ship.

Found what you need? It installs in one line.

And if you did not find it, the catalog document records the gap along with which application is waiting on it.
