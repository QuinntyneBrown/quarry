Questions

Before you adopt it.

Will it work in the app I already have?

If that app is on Angular 21 and Node 22, yes. Cornerstone declares the CDK as a peer dependency and ships nothing global beyond the theme stylesheet you name yourself, so it can sit beside whatever you are using today.

How much can I change without forking it?

Color, type, spacing, radius, shadow, motion, and container widths are all CSS custom properties. Set them on :root for the whole application or on any ancestor element to re-theme one subtree. Nothing needs recompiling.

How is accessibility actually verified?

Every build runs axe-core against rendered components in Chromium, Firefox, and WebKit, alongside unit tests for focus order, ARIA relationships, and keyboard interaction. Reduced-motion and forced-colors behavior are part of the theme rather than an opt-in.
