# Adopt the qbc-grid repository layout

Implement the approved library-oriented layout: direct feature folders under
`src/cornerstone`, independent docs/dev/e2e apps, static marketing under `src`, root
design-system tokens, root tooling under `tools`, and browser page objects/specs.

Preserve public exports, selectors, style entry points, deployment destinations,
quality thresholds, and documentation behavior. See `docs/repository-layout.md` for
the resulting decisions and `AGENTS.md` for the authoritative placement rules.

Ordered tasks and verification are recorded in `tasks/todo.md`.
